# Yash Kumar Dewangan — Portfolio

## Design blueprint

- **Audience:** product teams, hiring managers, founders, and collaborators who value both frontend craft and reliable full-stack delivery.
- **Positioning:** a product-minded MERN developer — clear thinking, tactile interfaces, pragmatic systems.
- **Story:** intent → selected work → working approach → capabilities → proof → conversation.
- **Visual language:** warm editorial paper, near-black ink, electric blue as a precise accent, high-contrast oversized typography, fine architectural rules, geometric project art.
- **Interaction:** progressive reveal on scroll, reduced-motion support, subtle smooth scrolling, responsive theme switcher, and purpose-led hover states.
- **UX principles:** make the work legible first; use animation as feedback; keep every section independently scannable; maintain a quick, low-image payload.

## Architecture

Next.js App Router, TypeScript, Tailwind, Framer Motion, Lenis, Lucide icons, semantic HTML, server-rendered dynamic notes route, SEO metadata, and an accessible light/dark theme.

## Run locally

```bash
npm install
npm run dev
```

Replace the placeholder email and social URLs in `src/app/page.tsx` before publishing. Add a real GitHub username/API token in a server-side data module before enabling live activity.
